# 自計化レビュー v3.3（月次PL・BSの変動分析）

あしたの会計事務所の「自計化レビュー」（Claude版 v3.0）に、freee の月次推移と同じ階層の月次PL・BSと、
**仕訳帳から「なぜこの月にこれだけ動いたか」を推測する機能**を加えた版です。ブラウザで開くだけの1ファイルで、外部通信はしません。

配布ファイル：[`dist/自計化レビュー_v3.3.html`](dist/自計化レビュー_v3.3.html)

## 追加した機能

- **freee と同じ▶の階層**：月次PL・BSの科目名を押すと「取引先別・品目別・部門別」が開き、さらに▶で「未選択」と各タグの月別金額が出ます。
  - 内訳は仕訳帳から作ります（対象科目と同じ借方・貸方の取引先・品目・部門。記載がなければ「未選択」）。
  - BSは「月末残高」と「当月の増減」を切り替え。期首残高の内訳は仕訳帳に無いので「期首残高（内訳なし）」の行に分けます。
  - 帳票と仕訳の合計が合わないときは「帳票との差額（仕訳で未説明）」の行を出します。
  - 月次BSが未読込でも、仕訳から各科目の「当月の増減」を表示します。
- **月ごとの変動理由**：科目を開くと「変動の理由（仕訳から推測）」に月ごとの前月差・主な内訳・推測が並びます。前月から大きく動いた金額は色付きで表示します。
- **右側の分析パネル**：金額・内訳・理由・カードを押すと、その月について
  「取引から分かること」（前月→当月、取引先・品目別の内訳、相手科目、最大の取引）と
  「理由の推測」（確からしさ 高・中・低）を分けて表示し、根拠の仕訳を金額順に確認できます。◀▶で前後の月へ移動できます。
- **大きく動いた科目と理由**：全科目から大きな変動を拾い、主因と推測をカードで一覧（月で絞り込み可）。
- **確認キュー**：「前月から大きく変動」の候補に、仕訳から見た理由を表示し、メモにも転記します。
- **AIに相談する文章をコピー**：根拠の仕訳付きで、Claude などに詳しく聞くための質問文を作ります。
- **v3.2（統合版）の全体バックアップの復元**：v3.2 の「修正済み」「修正不要」は「確認済み」にして、メモの先頭に元の状態を残します。

### 推測の例

| 状況 | 推測 |
| --- | --- |
| 事業主貸が増えた月に、個人名の取引先へ口座から振込 | 「○○（個人名）への支払い：事業主本人・家族への送金や生活費など」 |
| セゾンカードの残高が増えた | 利用額と口座引落しの差、利用先ごとの増減（Google・Facebook など）、引落しが無い月・2回ある月 |
| 給料・家賃が0円の月と約2倍の月 | 「翌月に2か月分を計上」「前月分を当月にまとめて計上」「2か月分計上の反動」 |
| 2か月ごとに計上される売上 | 「隔月の取引で当月は計上のない月」 |
| 租税公課の品目が自動車税・固定資産税・事業税 | 納期の時期、前年同月の同額、住民税・所得税の経費計上の注意 |
| 売掛金が増えた・預金が減った | 入金の遅れ（前月の売上の入金が無い）、遅れていた入金のまとめ入金 |
| 年払い・キャンペーン・PC購入など | 摘要・品目・メモのキーワードから単発の取引と判断 |

推測は仕訳の科目・取引先・品目・摘要・相手科目・前年同月から作る候補です。事実は証憑・通帳・お客様への確認で確かめます。

## 使い方

1. `dist/自計化レビュー_v3.3.html` をブラウザで開き、会社を選ぶ。
2. 「資料の読込」で freee の仕訳帳CSV（借方・貸方の取引先・品目・部門の列を含む全件）を読み込む。
   月次PL・月次BS（freee の月次推移CSV、円単位・内訳を閉じて出力）も読み込むと、帳票の金額と照合しながら分析できます。
   前年の仕訳帳を「過去の仕訳帳」に入れると、前年同月との比較も使います。
3. 「月次PL・BS」画面で科目の▶を押す、または金額を押す。

旧版のデータは、旧版の「全社バックアップ」（v3.2 は「全体バックアップ」）を保存し、この版の「復元」で読み込みます。

## ファイル構成

| パス | 内容 |
| --- | --- |
| `base/jikeika-review-v3.0.html` | 土台にした Claude版 v3.0（変更しない） |
| `src/variance.js` | 変動分析エンジン（内訳の集計・相手科目・推測ルール） |
| `src/monthly-page.js` | 月次PL・BS画面（freee風の階層表・右側パネル・カード） |
| `src/monthly-page.css` | 上記の見た目（明るめ・近未来の両テーマ、スマホ幅に対応） |
| `build.py` | base に src を組み込み `dist/` を作る |
| `tests/` | 架空データの freee 形式CSVと、Node・ブラウザのテスト |

## ビルドとテスト

```sh
python3 build.py              # dist/自計化レビュー_v3.3.html を作る
node tests/make-fixtures.js   # 架空の freee 形式CSV（tests/fixtures）を作り直す
node --test tests/variance.test.js
node tests/ui-smoke.js        # Chromium で画面操作（Playwright）
node tests/ui-import.js       # 画面の「CSV読込」から取り込む流れ
```

テスト用のデータ（やまだデザイン事務所、ヤマダタロウ ほか）はすべて架空です。
