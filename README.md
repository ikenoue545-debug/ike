# 自計化レビュー v3.7（目次と、取引先別の期首推定）

あしたの会計事務所の「自計化レビュー」v3.6 に、次の2つを加えた版です。ブラウザで開くだけの1ファイルで、外部通信はしません。

配布ファイル：[`dist/自計化レビュー_v3.7.html`](dist/自計化レビュー_v3.7.html)

## v3.7 で追加したこと

### 1. 月次PL・BS画面の目次

画面の上（メニューの下）に目次を固定しました。押すとその欄へすぐ移動し、いま見ている欄は目次の色が変わります。

- 資料の読込範囲と数値照合 ／ 資金の動きと、回収・支払の残り ／ 取引先別の残高と回収・支払の状況 ／ 大きく動いた科目と理由 ／ 今見るべき科目 ／ 月次PL ／ 月次BS ／ 売掛金の残高と増減 ／ 帳票と仕訳の照合 ／ 取り込む資料
- 欄は見出しの文字で探すので、▶の開閉などで欄が描き直されても行き先は変わりません。読み込んでいない資料の欄は目次にも出ません。
- スマホでは短い名前（数値照合・資金・回収・月次PL…）を横に並べ、右端の ▲ でページの先頭へ戻れます。印刷には出ません。

### 2. 取引先別の期首残高を、過去の仕訳帳から推定

売掛金・未収入金・買掛金・未払金・未払費用について、読み込んだ過去の仕訳帳から**取引先別の期首残高**を推定し、
当期の仕訳で月末まで繰り越して「どの取引先の回収・支払が止まっているか」「主要な取引先はどこか」を示す欄
「取引先別の残高と回収・支払の状況」を加えました。

推定のしかた（取引先ごと）：

1. 期首の前月末から過去へ、仕訳を連続して読める月（読取エラー・資料間の重複・参照除外のない月）だけを使う。
   仕訳が1件もない月は、同じCSVの期間の内側なら「取引のない月」として続けて読む。
2. 同じ仕訳の同じ取引先・同じ向きの行（手数料を別行にした入金など）は1件にまとめ、増えた分（請求・仕入）を積み、減った分（入金・支払）で消し込む。同じ金額の請求（または続いた請求の合計がちょうど一致するもの）があればそれを、なければ古いものから消し込む（先入先出）。
3. 読込範囲の始め（3か月）で、消し込む相手のない減少や、残っている請求が後で同じ金額で入金されている減少は、それより前からの残高の回収・支払とみなす（それ以上はないとした最小額）。読込範囲の途中で初めて出てくる取引先の減少も同じとみなす（ただし90日以内にそれを上回る請求・仕入が続けば前受・前払）。それ以外で相手のない減少は、前受・過入金（マイナスの残高）として次の請求に当てる。
4. 取引先が未選択の入金・支払は、同じ金額の未消込が1社だけにあればその取引先に当てる（候補として表示し、当てない場合の値も併記）。
5. 推定の合計を BS の期首と比べ、差は「内訳不明」に残して取引先には配分しない。合計が一致しても、取引先別の内訳の証明ではない。
6. 取引先内訳つきの BS（当期・前期）がある取引先は、その確定値を期首として、当期の仕訳で同じように消し込む。

表示すること：

- 回収・支払が止まっている可能性のある取引先（いちばん古い未回収・未払の日付と経過、ふだんの回収・支払日数との比較）
- 取引先ごとの期首（推定／確定）・当期の請求と入金（仕入と支払）・残高・状態・主要取引先（当期の請求・仕入の多い順）
- 期首の推定が当期の入金・支払で消し込まれたか（推定の裏付け）
- BS の期首・残高との照合と「推定の確からしさ」（高・中・低）
- 確認キューにも「回収（支払）が止まっている可能性のある取引先」として出る
- 月次BSの取引先別の内訳で「取引先別の推計（過去の仕訳から）」を選ぶと、同じ推定で月末残高を表示

推定は参考値です。延滞・期日超過を確定するものではなく、確定値（取引先内訳つきBSやそこからの繰越）とは混ぜません。

- 過去の仕訳帳がない・期首の前月まで途切れているときは、取引先別の期首と残高を「—」にし（0円とは扱わない）、当期の請求・入金だけを示します。
- 未選択の入金・支払を金額の一致で当てた科目は、推定の確からしさを「中」以下にし、当てない場合の期首も併記します。
- 前期BSと当期BSの期首が食い違うなど、BSの期首を確定できないときは「確定できません」とし、照合しません。
- 推定の途中でエラーが起きたときは、欄にその旨を出します（他の欄の数値には影響しません）。
支払・入金の多くに取引先が付いていない科目（カード払いの未払金など）や、未選択の支払で払われた可能性がある取引先は、状態を判定しません。

## 使い方

1. `dist/自計化レビュー_v3.7.html` をブラウザで開き、会社を選ぶ。
2. 「資料の読込」で freee の仕訳帳CSV（借方・貸方の取引先・品目・部門の列を含む全件）と、月次PL・月次BS を読み込む。
3. 前年以前の仕訳帳を「前期・過去の仕訳帳（複数年）」として読み込む（期首の前月まで途切れずに）。
4. 「月次PL・BS」画面の目次から「取引先別の残高と回収・支払の状況」へ移動する。

旧版のデータは、旧版の「全社バックアップ」を保存し、この版の「復元」で読み込みます（保存データの形は v3.6 と同じです）。

## ビルドとテスト

```sh
python3 build.py                     # dist/自計化レビュー_v3.7.html を作る
node tests/make-fixtures.js          # 架空の freee 形式CSV（tests/fixtures）を作り直す
node --test tests/party-opening.test.js tests/variance.test.js
node tests/ui-smoke.js               # Chromium で画面操作（Playwright）
node tests/ui-import.js              # 画面の「CSV読込」から当期・過去の仕訳帳とPL・BSを取り込む流れ
```

テスト用のデータ（やまだデザイン事務所、ヤマダタロウ、レッドストーン ほか）はすべて架空です。
