- 記録日：2026年10月16日
- 計算エンジン：taxengine 0.2.0
- 様式：国税庁「令和8年4月1日以後終了事業年度等分」

## 1 検証の方法と、検証済みと言える範囲

- 期待値は、国税庁の様式・記載要領・改正の概要（設計書13の一次資料）に従って**手計算**し、テストのコメントに計算過程を残しています。
- **国税庁の記載例や、税理士が作成した実際の申告書との照合はまだしていません。** 税理士等の専門家によるレビューも受けていません（画面「税率・法令」でも、すべての版が「専門家レビュー：未」です）。
- 下の表の「検証済み」は「手計算の期待値と一致する自動テストがある」という意味です。テストのない部分は「未実施」と書いています。

## 4 対応済みの機能

| 区分 | 内容 |
| --- | --- |
| 顧問先・年度 | 一覧（決算月・申告期限・担当者・進捗8段階・未解決エラー数・最終更新日）、会社情報（法人番号の検査、本店所在地から地方税の申告先の候補、申告期限の延長月数）、事業年度、進捗の履歴 |
| 取込 | CSV（UTF-8・Shift_JIS）・Excel（.xlsx）。見出し行の検出、列の自動マッピングと確認、見出し・小計の行の読み飛ばし、BS・PL の分割取込と取り込み直し、仕訳帳 |
| 試算表の検証 | 科目の分類（標準科目表と見出し）、未分類の検出、期首＋借方−貸方＝期末、借方合計＝貸方合計、資産＝負債＋純資産（当期純利益を含むかの自動判定）、仕訳帳との照合、マイナス残高 |
| 税務調整 | 規則による候補の抽出（役員給与の月額の変動・役員賞与・寄附金・減価償却・受取配当・罰金）、4段階の判定、採用／理由付きの不要、確認済み、根拠条文・確認事項・根拠資料（月別の支給額）、仕訳の摘要から延滞税等の検出 |
| 申告書 | 別表一（本表・次葉一・次葉二）、四、五(一)、五(二)、六(一)、七(一)、十五。地方法人税、防衛特別法人税。別表間の連動と再計算、検算（別表四の①＝②＋③、別表五(一)の検算、別表五(二)と五(一)、前期との連続性） |
| 計算根拠 | すべての欄に計算式・参照した欄・根拠・出所。欄の上書き（理由必須・履歴・取消し） |
| ルール | 年度別の版（根拠資料・URL・適用開始日・終了日・適用法人・条件・確認日・確認者・状態）、専門家の確認の記録、使った版の保存 |
| レビュー | 重大エラー・要確認・参考情報、移動先、要確認の確認済み、必要な別表・書類の判定、承認（重大エラーがあれば不可、レビュー担当者・管理者のみ）、承認の取消し、申告済、翌期への引継ぎ |
| 出力 | Excel（概要・別表ごと・計算根拠・指摘・使ったルール）、CSV（全欄）。いずれもドラフト |
| セキュリティ | 認証、役割、会社単位の権限、監査ログ、削除、アップロードのハッシュ、外部AIへの送信なし |

## 6 確認できていない点（専門家に確認してほしい点）

- 防衛特別法人税の基礎控除額（500万円×月数/12）の1円未満の端数処理（法令の明文を確認できていません。1円未満切捨てで表示し、短い事業年度では「参考情報」を出します）。
- 交際費等の定額控除限度額（800万円×月数/12）の1円未満の端数処理（同上。1円未満切捨て）。
- 納税充当金から損金不算入の附帯税を支出した場合の別表四の両建て（減算・留保と加算・社外流出）の表示方法。
- 仮払経理した事業税の別表四での減算の名称と行（「21」その他の減算に「仮払経理した事業税等（認定損）」として記載）。
