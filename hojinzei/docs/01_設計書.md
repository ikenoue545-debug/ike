# 法人税申告書AIアシスタント 設計書（Phase 1・2）

- 作成日：2026年10月16日
- 対象様式：国税庁「令和8年4月1日以後終了事業年度等分」の別表（2026年10月16日に国税庁サイトから取得して行番号を確認）
- 位置づけ：このリポジトリの既存アプリ（自計化レビュー）とは別のアプリです。`hojinzei/` 以下にまとめ、既存ファイルには手を入れません。

> この文書の税務上の記述は、末尾「13. 一次資料の確認記録」に挙げた国税庁の資料で確認したものです。税理士による確認はまだ受けていません。システム上も、ルールデータごとに「専門家レビュー：未」と表示します。

## 1. システムの全体構成

```
┌──────────────────────── ブラウザ ────────────────────────┐
│ Next.js（React / TypeScript / Tailwind CSS）                │
│  顧問先一覧 / 会社情報・資料 / 試算表 / 期首情報 /          │
│  税務調整 / 申告書プレビュー / 最終チェック / 税率・法令     │
└───────────────┬───────────────────────────────────────────┘
                │  /api/*（Next.js の rewrites で中継。同一オリジン）
┌───────────────▼───────────────────────────────────────────┐
│ FastAPI（app/）                                            │
│  routers/   … HTTP の入口（認証・権限チェック・監査ログ）     │
│  services/  … 取込・列マッピング・科目分類・試算表検証・      │
│               税務調整候補の抽出・エンジン入力の組立・出力    │
│  models.py  … SQLAlchemy（PostgreSQL / SQLite 両対応）       │
└───────┬──────────────────────────────┬────────────────────┘
        │ 入力（dataclass）             │ 結果（セル・根拠・指摘）
┌───────▼──────────────────────┐      │
│ taxengine/（独立した計算エンジン）│◄─────┘
│  rules/data/*.json … 年度別の税率・ルール（根拠・適用期間・確認者）│
│  schedules/ … 別表ごとの計算    engine.py … 依存順に実行      │
│  checks.py … 別表間の整合性     cells.py … 計算根拠の記録      │
└──────────────────────────────┘
        PostgreSQL（会社・年度・取込データ・税務調整・計算結果の保存・監査ログ）
```

分離の方針

| 層 | 責務 | 依存してよいもの |
| --- | --- | --- |
| `taxengine` | 税額計算・別表作成・整合性チェック。入出力は Python の dataclass。DB・HTTP・AI を知らない | 標準ライブラリのみ |
| `app/services` | 取込（CSV・Excel）、科目分類、試算表の検証、DB の値からエンジン入力を組み立てる、出力（Excel・CSV） | `taxengine`、DB |
| `app/routers` | 認証・権限・監査ログ・入力検証（Pydantic） | services |
| `frontend` | 表示と入力。計算はしない（表示用の合計もサーバーの値を使う） | API |

- 金額はすべて **整数円**（Python の `int`）。税率は `Decimal`（文字列で定義）。浮動小数点は使いません。
- 生成AIは Phase 4 から。Phase 1・2 の「税務調整候補の抽出」は **規則による抽出** で、画面にもそう表示します。

## 2. 対象範囲と、自動計算をしない場合

### 初期対応（Phase 2 で計算するもの）

- 内国法人である普通法人（株式会社・合同会社）、青色申告、確定申告
- 期末資本金1億円以下の中小法人（大法人の100％子会社等でないことを利用者が確認したもの）
- 12か月の事業年度、設立初年度などの短い事業年度（月数按分）
- 黒字・赤字、繰越欠損金（青色欠損金）
- 法人税（別表一・四・五(一)・五(二)・六(一)・七(一)・十五）、地方法人税、防衛特別法人税

### 自動計算をせず「対象外・未対応」として確定を止めるもの

| 条件 | 理由・対応予定 |
| --- | --- |
| グループ通算制度 | 別表一付表・別表四付表・七(二)が必要。未対応 |
| 期末資本金1億円超、大法人の100％子会社等、適用除外事業者に該当／不明 | 税率・交際費・欠損金の扱いが変わる。「不明」は未確定として止める |
| 白色申告 | 欠損金の繰越しの扱いが異なる。Phase 3 |
| 公益法人等・協同組合等・外国法人 | 未対応 |
| 修正申告・中間申告（仮決算） | 未対応（確定申告のみ） |
| 特別税額控除（別表六(六)以下）、外国税額控除、土地譲渡利益金、留保金課税 | 未対応。該当ありと入力されたら止める |
| 複数の都道府県・市町村に事務所 | 分割基準の自動確定は禁止（仕様8） |
| 地方税（住民税・事業税・特別法人事業税）の税額計算 | Phase 3。Phase 2 では利用者が入力した税額を別表五(二)に使い、「要確認」を付ける |
| 適用できるルールの版がない事業年度（例：中小法人の軽減税率の特例期限後に開始する事業年度） | 法令の確認が済むまで確定を止める |

## 5. 計算エンジンの設計

### 5.1 入力

`ReturnInput`（dataclass）にまとめます。DB に依存しません。

- `profile`：法人の種類、期末資本金、大法人の100％子会社等か、適用除外事業者か、通算か、青色か、申告区分、対象外の論点
- `period`：事業年度の開始日・終了日（月数は暦に従い、1か月未満の端数は1か月）
- `accounts`：当期純利益、繰越利益剰余金・利益準備金・積立金の期首と期末、納税充当金（未払法人税等）の期首と期末、配当
- `adjustments`：税務調整（金額が `None` なら未確定）
- `tax_payments`：別表五(二)の各行（期首未納①・当期発生②・充当金取崩し③・仮払経理④・損金経理⑤）
- `withholding`：源泉所得税（別表六(一)）。記帳方法（費用／受取額から差引／仮払）
- `entertainment`：交際費等の額・控除される費用・接待飲食費（別表十五）
- `opening`：期首の利益積立金の各行・資本金等・繰越欠損金
- `local_taxes`：Phase 2 は手入力の住民税・事業税（確定分）
- `overrides`：上書き

### 5.2 セルと計算根拠

すべての欄を `Cell` として記録します。

```
Cell(key="b4.52.total", schedule="別表四", line="52", column="①総額",
     label="所得金額又は欠損金額", value=1234000 or None,
     formula="(45) + (46)〜(51)", refs=["b4.45.total", ...],
     basis=["法人税法第22条"], source="computed" | "input" | "override",
     notes=[...])
```

- 入力が足りない欄は `None`（未確定）。`None` を含む計算の結果も `None` になり、0円で埋めません。
- 上書きがある欄は、計算した値と上書きの値の両方を残し、以後の計算は上書きの値を使います（指摘「要確認」）。
- 画面の「計算過程」は、この `formula` と `refs` をたどって表示します。

### 5.3 端数処理（国税）

| 対象 | 処理 | 根拠 |
| --- | --- | --- |
| 課税標準（所得金額、課税標準法人税額） | 1,000円未満切捨て | 国税通則法第118条第1項 |
| 確定金額（差引所得に対する法人税額、差引地方法人税額、差引防衛特別法人税額 等） | 100円未満切捨て | 国税通則法第119条第1項 |
| 年800万円・交際費800万円・基礎控除500万円の月数按分 | 様式の「000」欄は1,000円未満切捨て、それ以外は1円未満切捨て | 様式の記載（別表一次葉二「74」は千円単位）。基礎控除の按分の端数は法令の明文を未確認のため「要確認」を付記 |
| 税率の乗算 | 1,000円単位の金額 × 税率（小数第3位まで）なので端数は出ない。出た場合は1円未満切捨てとし、指摘を出す | — |

### 5.4 ルールの版管理

`taxengine/rules/data/*.json` に、ルールごと・版ごとに保存します。

```json
{"id": "corporate_tax_rate", "title": "法人税の税率（普通法人）",
 "basis": "fy_start",
 "versions": [{
   "version": "2025-04", "valid_from": "2025-04-01", "valid_to": "2027-03-31",
   "applies_to": "普通法人", "conditions": "…",
   "values": {"standard_rate": "0.232", "sme_rate": "0.15", "sme_rate_income_over_1bn": "0.17", …},
   "sources": [{"title": "令和7年度 法人税関係法令の改正の概要（国税庁）", "url": "…", "provisions": "法人税法第66条、租税特別措置法第42条の3の2"}],
   "status": "source_checked", "checked_by": "Claude（AI）による一次資料との照合",
   "checked_at": "2026-10-16", "expert_review": "未"}]}
```

- `basis`：判定の基準日（`fy_start` 事業年度開始日／`fy_end` 終了日／`expense_date` 支出日）。
- 事業年度に合う版がない、または版が `status: "unverified"` のとき、その計算は `None` とし重大エラーにします。
- 計算結果の保存時に、使った版（id と version）を `return_snapshots` に記録します。過年度は当時の版で再計算できます（版は削除せず追加する運用）。

## 6. 別表間の計算依存関係

```

   ├─► 別表十五 交際費等 ─────────┐            │
   ├─► 別表五(二) 租税公課 ──┐     │            │
   │   （納付状況・納税充当金）│     │            │
   │                        ▼     ▼            ▼
   ├─► 税務調整 ─────────► 別表四（1〜43）◄──────┘（29 加算・社外流出）
   │                        │ 43①（控除前所得）
   │                        ▼
   │                 別表七(一) 欠損金 ──► 別表四 44（当期控除額）
   │                        │
   │                        ▼
   │                 別表四 52（所得金額）
   │                        │
   │                        ▼
   │     別表一（法人税額 2〜15、所得税額控除 16〜21）
   │                        │ 法人税額（2）−（3）＋…
   │                        ├─► 地方法人税（28〜40、次葉二 80〜83）
   │                        └─► 防衛特別法人税（次葉一 45〜73）
   │                        │
   │       確定税額（15・40・59）＋地方税（入力）
   │                        ▼
   └──────────────► 別表五(二) 当期確定分（4②・9②・14②）
                            ▼
                 別表五(一)（利益積立金：別表四の留保＋未納法人税等）
                            ▼
                 検算：期首31① ＋ 別表四52② − 中間・確定の法人税等・住民税 ＝ 期末31④
```

### 循環参照について

- 当期の法人税等は「損金経理をした納税充当金」として別表四で全額加算するので、課税所得は当期の税額に依存しません。決算で税額を計上する前でも後でも、所得金額は同じです（計上前なら「計上すべき未払法人税等」を表示します）。
- 寄附金の損金算入限度額（Phase 3）は、別表四の仮計（26）に寄附金の支出額を足した額を基礎にする様式の定めに従い、反復計算はしません。
- 事業税は申告した年度の損金（納税充当金から支出したものは別表四「13」で減算）なので、当期の事業税は当期の所得に影響しません。
- このため Phase 2 の範囲では反復計算が要りません。エンジンは上の順番で一度だけ計算します。順番はテストで固定します。

## 7. 別表ごとの計算（様式の行番号）

様式：令和8年4月1日以後終了事業年度分（別表一は三枚：本表・次葉一・次葉二）。

### 7.1 別表四（所得の金額の計算に関する明細書）

| 行 | 内容 | ① 総額 | ② 留保 | ③ 社外流出 |
| --- | --- | --- | --- | --- |
| 1 | 当期利益又は当期欠損の額 | PL の当期純利益 | ①−③ | 配当（効力が当期に生じたもの）・その他 |
| 2 | 損金経理をした法人税、地方法人税及び防衛特別法人税 | 別表五(二) 5⑤ | 同左 | |
| 3 | 損金経理をした道府県民税及び市町村民税 | 五(二) 10⑤＋15⑤ | 同左 | |

## 8. 判定と指摘の段階

税務調整の判定（4段階）：

1. 自動確定可能：計算の材料がそろい、規則で確定できる（例：五(二)から導く納税充当金の加算）
2. 要確認：処理案はあるが人の判断が要る（例：交際費の科目に計上があるが、接待飲食費の内訳が未入力）
3. 資料不足：判断に必要な情報がない（例：減価償却費があるが固定資産台帳がない）
4. 対象外・未対応：今の機能では処理できない

指摘（3段階）：重大エラー（確定を止める）／要確認／参考情報。各指摘は「どこが」「なぜ」「どう直すか」と移動先を持ちます。重大エラーは確認済にできません。

## 12. セキュリティ（この版）

- パスワードは scrypt でハッシュ化。トークンはハッシュで保存、期限付き
- 会社単位のアクセス権、役割による操作制限（承認はレビュー担当者・管理者）
- 監査ログ（操作・対象・利用者・日時。金額や個人情報はログに出さない）
- アップロードファイルは SHA-256 を記録し、会社・年度ごとのディレクトリに保存
- 外部AIへの送信はなし（Phase 4 で、送信内容の明示と承認を入れてから）
- 本番では HTTPS の終端（リバースプロキシ）とディスク暗号化、DB のバックアップを前提にする（README に記載）。保存データの列単位の暗号化は未実装
