## そろえる資料（freee から CSV で出力）

| 資料 | freee での出し方 |
| --- | --- |
| 当期の仕訳帳 | 仕訳帳 → CSV（取引先・品目・部門の列を含む全件） |
| 前期・過去の仕訳帳 | 同上（期首の前月まで途切れずに。複数年可） |
| 月次BS × 取引先・品目・部門 | 月次推移 → 貸借対照表 →「表示するタグ」を取引先／品目／部門にして、それぞれ CSV |
| 月次PL × 取引先・品目・部門 | 月次推移 → 損益計算書 → 同上 |

- 円単位、「分類と勘定科目」は「同じ列にする（一列）」で出力してください。
- タグ別のCSVには科目合計も入っているので、「表示するタグ＝なし」のCSVは要りません。
- 資料の読込画面の「CSVをまとめて選ぶ（自動判定）」で、全部を一度に選べます。種類（仕訳帳・BS・PL、当期・前期）とタグの種類は自動で判定します。読めないファイルは「この資料をとばして次へ」で飛ばせます。

## v3.9 で直したこと・加えたこと

### 1. タグ別の月次BS・PLを読めるようにした（v3.7・v3.8 で読めなかった原因の修正）

v3.7 も v3.8 も、品目・部門の列やPLの取引先の列があると「二重計上を防ぐため」読み込みを止めていました。v3.8 の新しい読み取り処理は、freee が実際には出さない形（「取引先別」の見出し行）を前提にしていて、実際のCSVには一度も当たっていませんでした。

- 見出しの3列目（取引先・品目・部門・セグメント1〜3）からタグの種類を判定し、BS・PLとも、科目合計とタグ別の内訳を分けて読みます。
- 科目ごと・月ごとに「内訳の合計＝科目合計」を照合します（未選択を含む）。合わない科目の内訳だけを外し、理由を表示します（科目合計は取り込みます）。
- 内訳は科目合計に足しません。BSの取引先別は従来どおり回収・支払の確認に使い、それ以外は別の置き場（`session.tagReports`）に保存します。
- 取り込みは「同じ帳票・同じタグ」の分だけ置き換えます。取引先別・品目別・部門別のBSを順に読んでも、ほかのタグ別の内訳は残ります。科目合計が前の帳票と違うとき（出力時点の違い）は、読み込む前に知らせます。
- BSのタグ別の値は、freee では期首からの累計です。未選択に相殺額がある科目（現金・預金・カード、事業主貸など）は、残高ではなく「累計の動き」として表示します。

### 2. 月次PL・BSの「表示するタグ」

PL・BSの表の上に、freee と同じ「表示するタグ：なし｜取引先｜品目｜部門」を置きました。選ぶと、すべての科目の下にそのタグ別の内訳が出ます。

- 読み込んだ帳票の値を使い、帳票がないときは仕訳から集計します。
- PLで、帳票と仕訳の金額が違うタグには「仕訳との差」が付きます。
- 0円だけの行を隠す・金額の大きい順・検索・30件ずつのページ送りが使えます。印刷では全件を出します。

### 3. 取引先・品目・部門別の帳票（新しい欄）

- 資料の読込状況：BS・PL × なし・取引先・品目・部門 の一覧と、照合の結果。
- PL：タグ別の構成（当期累計・最新月・前月比・前年同期比）、主要な取引先の集中度、新しい／いなくなった取引先、部門別損益。
- BS：立替金・仮払金などで、タグ別の残高が3か月以上動かないもの（精算漏れ・付け間違いの可能性）。売掛金・買掛金などのタグ別のマイナス残高（過入金・二重払いの可能性）。
- 確認キューにも出ます（タグの付け漏れ、内訳の不一致など）。

### 4. 対応の順番（指摘をどの順に片付けるか）

確認キューの指摘を、次の6段階に並べ、段階ごとに「誰が動くか」を付けます。

1. 資料をそろえる（読込不足・帳票と仕訳の差・内訳の不一致）
2. 残高を確定する（現預金・期首のつながり・残高の差）
3. 回収・支払と仮勘定（回収・支払の停滞、仮払・立替の未精算）
4. 売上・経費の計上（月ズレ・漏れ・重複・大きな変動）
5. 税金と区分（消費税・源泉・私的支出）
6. 記帳のしかた（タグの付け漏れ・記帳ルール。次回から）

- 前の段階が片付かないと後ろの結果が変わるため、この順にしています。
- 誰が動くかは、資料の依頼／事務所で確認／お客様に質問／お客様に修正依頼／記録のみ、のいずれかです。
- 同じ論点の指摘は1件にまとめます。
- 「次にやること」を表示し、「お客様への確認リスト」をコピー・CSV・印刷で書き出せます。

### 5. 画面を軽くした（v3.8 から移植）

取引先が800社ほどの資料では、v3.7 の月次画面は HTML が 87MB・約1,000,000要素になり、開くのに数秒〜十秒固まっていました。閉じている欄は開いたときに描き、長い一覧はページ送りにして、0.23MB・約2,700要素・0.6秒になりました。資金の動き・照合・取引先別の残高の欄に検索とページ送りを付け、取引先別の残高はCSVで書き出せます（数式として扱われないよう対策済み）。

### 6. 使い勝手

- 対象期間を決算月から自動で設定します（自分で決めた期間は変えません）。仕訳帳に対象期間より後の行があれば「対象期間を◯◯まで広げる」ボタンが出ます。
- 資料の読込画面を、主な4つ（当期・前期の仕訳帳、月次BS、月次PL）と「追加資料（任意）」に分けました。BS・PLのカードには、どのタグ別を読み込んだかの一覧が出ます。
- 監査の欄に残っていた特定の取引先名の文言を、一般的な説明に直しました。

## v3.7 からの機能（目次・取引先別の期首推定）

- 月次PL・BS画面の目次（押すとその欄へ移動）。
- 売掛金・未収入金・買掛金・未払金・未払費用の取引先別の期首を、過去の仕訳帳から推定します。そのうえで、回収・支払が止まっている可能性のある取引先を示します。取引先別BSがあれば、その確定値を使います。

## ビルドとテスト

```sh
python3 build.py                     # dist/自計化レビュー_v3.9.html を作る
node tests/make-fixtures.js          # 架空の freee 形式CSV（tests/fixtures）を作り直す
node --test tests/*.test.js          # Node のテスト
node tests/ui-smoke.js && node tests/ui-import.js && node tests/ui-data.js && node tests/ui-tags-import.js   # Chromium で画面操作（Playwright）
```

テスト用のデータ（やまだデザイン事務所（架空）ほか）はすべて架空です。お客様の実データはリポジトリに入れていません。
